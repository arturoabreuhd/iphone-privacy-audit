# Photos.sqlite Schema Reference

This is a reference for the key tables and fields in Apple's Photos.sqlite database. iOS versions may add/rename fields — always verify with `.schema` before querying.

---

## ZGENERICASSET (or ZASSET) — Main photos/videos table

| Field | What it means |
|---|---|
| Z_PK | Primary key (unique ID per asset) |
| ZKIND | 0 = photo, 1 = video |
| ZPLAYBACKSTYLE | 0 = image, 1 = video, 3 = live photo, 4 = slo-mo |
| ZDATECREATED | Timestamp (Core Data: seconds since 2001-01-01) |
| ZMODIFICATIONDATE | Last modified |
| ZLATITUDE, ZLONGITUDE | GPS coordinates |
| ZTRASHEDSTATE | 0 = active, 1 = in Recently Deleted |
| ZTRASHEDDATE | When it was deleted |
| ZFILENAME | e.g. IMG_1234.HEIC, IMG_5678.MOV |
| ZDIRECTORY | e.g. DCIM/100APPLE |
| ZORIGINALFILESIZE | File size in bytes (via ZADDITIONALASSETATTRIBUTES) |
| ZDURATION | Video duration in seconds |
| ZWIDTH, ZHEIGHT | Resolution |
| ZFAVORITE | 1 = favorited |
| ZHIDDEN | 1 = hidden |

**Timestamp conversion:** `datetime(ZDATECREATED + 978307200, 'unixepoch', 'localtime')`

## ZDETECTEDFACE — Facial recognition data

| Field | What it means |
|---|---|
| Z_PK | Face ID |
| ZASSET | Foreign key to ZGENERICASSET |
| ZPERSON | Foreign key to ZPERSON (if identified) |
| ZAGETYPE | 1=baby, 2=child, 3=young adult, 4=adult, 5=senior |
| ZGENDERTYPE | 1=male, 2=female |
| ZBALDTYPE | Baldness classification |
| ZEYESSTATE | 1=open, 2=left closed, 3=right closed, 4=both closed |
| ZFACIALHAIRTYPE | Facial hair classification |
| ZGLASSESTYPE | 0=none, 1=glasses, 2=sunglasses |
| ZHASSMILE | 0=no, 1=yes |
| ZSKINTONETYPE | Skin tone (1-6 scale) |
| ZHAIRCOLARTYPE | Hair color classification |
| ZFACEEXPRESSIONTYPE | Expression classification |
| ZQUALITYMEASURE | Face detection quality score |
| ZCENTERX, ZCENTERY | Face position in frame |
| ZSIZE | Face size relative to frame |
| ZROLL, ZYAW | Head angle |

## Media Analysis Tables — Deep ML analysis

These tables contain the heavy ML analysis. Names vary by iOS version. Common patterns:

### ZCOMPUTEDATTRIBUTES or ZMEDIAANALYSISASSETATTRIBUTES

| Field | What it means |
|---|---|
| ZASSET | Foreign key |
| ZSCREENTIMEDEVICEIMAGESENSITIVITY | -1=not analyzed, 0=safe, 1=sensitive/explicit |
| ZANALYSISSTATE | Analysis completion state |

### Binary blobs (stored as BLOB fields)

These contain serialized ML analysis results:
- **Image captions**: Natural language descriptions generated by on-device ML
- **Image embeddings**: Vector representations for similarity search
- **OCR text**: Text extracted from photos via VNRecognizeTextRequest
- **Scene vectors**: Encoded scene classification data
- **Activity classification**: What's happening in videos

## Useful Relationships

```
ZGENERICASSET.Z_PK → ZADDITIONALASSETATTRIBUTES.ZASSET
ZGENERICASSET.Z_PK → ZDETECTEDFACE.ZASSET
ZDETECTEDFACE.ZPERSON → ZPERSON.Z_PK
ZDETECTEDFACE.Z_PK → ZDETECTEDFACEPRINT.ZFACE
ZGENERICASSET.Z_PK → ZCOMPUTEDASSETATTRIBUTES.ZASSET
```

## Important Notes

- Table and field names can change between iOS versions. Always run `.tables` and `.schema TABLE_NAME` first.
- Timestamps are Core Data format: seconds since 2001-01-01 00:00:00 UTC. Add 978307200 to convert to Unix epoch.
- Some tables may not exist on all iOS versions. Check before querying.
- Binary blobs (faceprints, scene data, OCR) require specialized parsing — often plist or protobuf encoded.
- The `ZTRASHEDSTATE = 1` assets are "deleted" but the actual files may still exist in DCIM.
